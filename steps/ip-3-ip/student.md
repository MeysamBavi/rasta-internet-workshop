در گام قبل سعی کردین برای دستگاه‌های اینترنت یک آدرس عددی بسازین. ایدهٔ اصلی این بود که آدرس فقط یک شمارهٔ تصادفی برای هر دستگاه نباشه: بخش‌های اولش محدودهٔ کلی مقصد رو نشون بدن و هر بخش تازه، جای مقصد رو دقیق‌تر کنه.

### آدرس IP

توی اینترنت هم از ایده‌ای شبیه همین استفاده می‌کنیم. هر دستگاه یک آدرس IP داره. احتمالاً قبلاً چیزی شبیه این دیدین:

`140.82.121.3`

این یک آدرس IPئه؛ به‌طور مشخص، یک آدرس IP version 4 یا IPv4. این آدرس یک عدد ۳۲ بیتی‌ه که برای راحت‌تر خونده‌شدن به چهار بخش تقسیمش می‌کنیم. هر بخش ۸ بیت داره و می‌تونه عددی بین ۰ تا ۲۵۵ باشه.

اما آدرس IP فقط یک عدد یا شمارهٔ شانسی نیست؛ واقعاً نقش یک آدرس رو بازی می‌کنه. در مثال آدرس خونهٔ سارا، پیشوند «فرانسه» کشور مقصد رو از بین همهٔ کشورهای دنیا مشخص می‌کرد. پیشوند «فرانسه، منطقهٔ ایل-دو-فرانس، شهر پاریس» جای مقصد رو دقیق‌تر می‌کرد. با اضافه‌شدن «خیابون ریولی»، محدودهٔ مقصد باز هم کوچک‌تر می‌شد.

بخش‌های ابتدایی آدرس IP هم تقریباً همین کار رو برای شبکه‌ها انجام می‌دن. این سه پیشوند رو ببینین:

1. `140.*.*.*`
2. `140.82.*.*`
3. `140.82.121.*`

پیشوند `140.*.*.*` یک محدودهٔ بزرگ از آدرس‌ها رو مشخص می‌کنه. 140.82.\*.\* محدودهٔ کوچک‌تری داخل همون محدوده‌ست و `140.82.121.*` باز هم محدوده رو کوچک‌تر و دقیق‌تر می‌کنه. آدرس `140.82.121.3` داخل همهٔ این محدوده‌ها، یا دقیق‌تر بگیم شبکه‌های تودرتو، قرار گرفته؛ درست مثل خونهٔ سارا که هم در فرانسه‌ست، هم در ایل-دو-فرانس، هم در پاریس و هم در خیابون ریولی.

بنابراین آدرس IP دو کار مهم انجام می‌ده: هم دستگاه مقصد رو مشخص می‌کنه، هم به روترها سرنخ می‌ده که برای رسیدن به شبکهٔ اون دستگاه، بسته رو به کدوم سمت هدایت کنن.

### دو مأموریت پژوهشی

این دو مأموریت جواب خاصی ندارن؛ فقط قراره رد پای واقعی خودتون رو در اینترنت ببینین.

1. به سایت[ What Is My IP Address](https://whatismyipaddress.com) برین. آدرس IP عمومی‌تون و اطلاعاتی رو که سایت درباره‌ش نشون می‌ده رو ببینین.
2. همون آدرس IP رو در سایت[ HackerTarget](https://hackertarget.com/as-ip-lookup) وارد و جست‌وجو کنین. نتیجه بهتون نشون می‌ده از نگاه کسی در اون طرف دنیا، شما بخشی از کدوم شبکهٔ بزرگ‌تر هستین.
