## کارتِ تقلب منتور

### این گام از کجا شروع می‌شه؟

بچه‌ها توی گام قبل برای روتر A یه راهنما ساختن که برای هر Destination Prefix، یه Next Hop مشخص می‌کرد.

حالا باید همین ایده رو برای همهٔ روترهای شبکه اجرا کنن. توی این گام نقشه ثابته، همهٔ اتصال‌ها سالم‌ان و بچه‌ها کل توپولوژی شبکه رو می‌بینن.

### قراره تهِ گام چه چیزی رو بفهمن؟

بفهمن که برای آماده‌کردن شبکه باید جدول مسیریابی هر روتر جداگانه تنظیم بشه و Next Hop مناسب ممکنه از دید روترهای مختلف فرق داشته باشه.

همچنین بفهمن که «بهترین مسیر» بدون داشتن یه معیار مشخص معنی نداره. توی این فعالیت، معیار بهینگی تعداد Hopهاست.

### فکر و مسیر کلیِ گام چیه؟

بچه‌ها اول معیار مقایسهٔ مسیرها رو مشخص می‌کنن. بعد با داشتن نقشهٔ کامل شبکه، برای همهٔ روترها جدول می‌سازن.

بعد از اون، جدول‌ها قفل می‌شن و چند بسته از مبدأهای مختلف توی شبکه حرکت می‌کنن. حلقه، بن‌بست یا انتخاب مسیر نامناسب فقط موقع حرکت بسته‌ها دیده می‌شه و گروه باید اولین تصمیم ناسازگار رو پیدا و اصلاح کنه.

### زمان مورد انتظار و نکته‌های مربوط بهش

حدود ۱۵ دقیقه:

1. ۲ دقیقه برای مشخص‌کردن معیار
2. ۸ دقیقه برای کامل‌کردن جدول‌ها
3. ۳ دقیقه برای آزمایش
4. ۲ دقیقه برای ارائه و جمع‌بندی

همهٔ اتصال‌های بین دو روتر هزینهٔ ۱ دارن.؟ پس Cost یه مسیر برابر با تعداد Hopهای اونه.

اگه دو مسیر Cost برابر داشته باشن، هر دو قابل‌قبول‌ان؛ مگر اینکه ابزار برای داشتن یه پاسخ مشخص به یه قانون برای شکستن تساوی نیاز داشته باشه.
